## Nanite Transmuter (Late-Game Equalizer)

A single Nanite Transmuter produces +5 of ALL three standard strategics simultaneously for -5 EC and -2 Nanites/mo. This can replace per-resource refineries for empires with nanite access. The Harbinger §11 supply model does not account for this building — flag for templates with Nanotech traditions.

**How to apply:** Use these values as the authoritative input for G4 gate checks and for verifying the Harbinger §11.1 demand table. All values confirmed against wiki 2026-04-12.
